# WorldWise 🌍

WorldWise is a React application that allows users to track cities and countries they have visited using an interactive map.  
The project focuses on modern React patterns, performance optimization, and real-world user interactions such as geolocation and map-based forms.

---

## ✨ Features

- Interactive map with clickable locations
- Load user’s current location
- Create and delete cities
- View cities and countries lists
- Map interaction synced with form inputs
- Lazy loading for improved performance
- Clean and intuitive UI

---

## 🛠️ Tech Stack

- **React**
- **Context API**
- **useReducer**
- **React Router**
- **Lazy Loading (code splitting)**
- **JavaScript (ES6+)**
- **Map library (e.g. Leaflet / Mapbox)**

---

## 🧠 State Management

Global state is managed using **Context API** combined with the **useReducer** hook.  
This approach replaces multiple `useState` hooks and provides a more scalable and predictable state flow.

---

## 🗺️ Map & Geolocation

- Users can load their current location
- Clicking on the map updates the city form automatically
- Cities are displayed and managed directly from the map interface

---

## 🚀 Getting Started

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/AyaHusein2001/world-wise.git
   ````

2. Install dependencies:

   ```bash
   npm install
   ```

3. Run the app:

   ```bash
   npm run dev
   ```
